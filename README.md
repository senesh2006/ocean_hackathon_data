# Ocean Hackathon data (Sri Lanka)

Team datasets for SplitWater / GAL02.

| Path | Contents |
|------|----------|
| `fish-data/` | Sri Lanka fish occurrences (OBIS, GBIF, FishBase), IOTC catch, env grids, merged clean set, `train_ready/features.parquet`. See `fish-data/README.md`. |
| `Fishing_sl.csv` | Global Fishing Watch monthly fishing hours per 0.1° cell, Sri Lanka, 2012–2024 (BigQuery export). |

Licences vary by source; see `fish-data/catalog.csv` and GFW terms for the effort file.
